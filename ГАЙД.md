# 🚀 Как закинуть сайт на GitHub и включить GitHub Pages

Гайд для вашей папки `C:\Users\Администратор\Documents\сайт`.
В ней уже готовы все файлы и автоматическая публикация:

```
сайт/
├── index.html                          ← страница
├── styles.css                          ← оформление
├── script.js                           ← ВАШИ имя и ссылки
├── .nojekyll                           ← служебный файл для Pages
├── README.md
├── ГАЙД.md
└── .github/
    └── workflows/
        └── pages.yml                   ← автопубликация
```

---

## Шаг 0. Перед началом — поставьте свои ссылки

Откройте `script.js` в Блокноте (или VS Code) и впишите свои данные:

```js
const profile = {
  name: 'Ваше имя',
  bio: 'Все мои ссылки — в одном месте.',
  links: {
    telegram: 'https://t.me/ваш_ник',
    vk: 'https://vk.com/ваш_ник',
    discord: 'https://discord.com/users/ваш_id',
    tiktok: 'https://www.tiktok.com/@ваш_ник',
  },
};
```

Сохраните файл. **Проверить результат до GitHub можно так:** двойной клик по `index.html` — откроется браузер.

> 💡 Discord ID узнать: Discord → Настройки → Дополнительно → Режим разработчика → правый клик по своему нику → «Копировать ID».

## Шаг 1. Зарегистрируйте аккаунт GitHub

Если аккаунта нет — https://github.com/signup

---

## Шаг 2. Установите Git

Скачайте с официального сайта: **https://git-scm.com/download/win**

Установите со стандартными настройками (везде «Next»).

После установки **закройте и снова откройте** PowerShell, затем проверьте:

```powershell
git --version
```

Должно ответить что-то вроде `git version 2.47.0`.

---

## Шаг 3. Настройте Git (один раз на весь компьютер)

В PowerShell выполните, подставив свои данные:

```powershell
git config --global user.name "Ваше Имя"
git config --global user.email "ваша-почта@example.com"
```

Почта должна совпадать с той, на которую зарегистрирован GitHub.

---

## Шаг 4. Создайте репозиторий на GitHub

1. Войдите в GitHub → нажмите **+** справа сверху → **New repository**  
   Прямая ссылка: https://github.com/new
2. **Repository name**: например `links`
3. **Visibility**: 🔴 **Public** (обязательно — Pages бесплатен только для публичных репозиториев)
4. ❗ НЕ ставьте галочки «Add README», «.gitignore», «license»
5. Нажмите **Create repository**

После создания GitHub покажет адрес вида:

```
https://github.com/ВАШ_НИК/links.git
```

Скопируйте его — он понадобится в Шаге 6.

---

## Шаг 5. Откройте папку сайта в PowerShell

```powershell
cd "C:\Users\Администратор\Documents\сайт"
```

Проверьте, что вы в нужной папке:

```powershell
dir
```

Должны увидеть `index.html`, `styles.css`, `script.js`, папку `.github`.

---

## Шаг 6. Загрузите файлы на GitHub

Выполните команды по одной, подставив свой адрес из Шага 4:

```powershell
git init
```

```powershell
git add .
```

```powershell
git commit -m "Мой сайт с ссылками"
```

```powershell
git branch -M main
```

```powershell
git remote add origin https://github.com/ВАШ_НИК/links.git
```

```powershell
git push -u origin main
```

При `git push` откроется окно входа GitHub — войдите через браузер, который уже залогинен. Готово: файлы загружены.

> Если Git попросит логин/пароль в консоли — используйте **Personal Access Token** вместо пароля. Создать: https://github.com/settings/tokens → Generate new token (classic) → отметьте `repo` → скопируйте токен. Логин — ваш ник, пароль — этот токен.

---

## Шаг 7. Включите GitHub Pages

1. Откройте репозиторий на GitHub
2. Вкладка **Settings** (шестерёнка сверху)
3. Слева в списке: **Pages**  
   Прямая ссылка: `https://github.com/ВАШ_НИК/links/settings/pages`
4. В блоке **Build and deployment** → **Source** выберите **GitHub Actions**

Больше ничего нажимать не нужно — публикация начнётся сама.

---

## Шаг 8. Дождитесь публикации

1. Перейдите во вкладку **Actions** вашего repo:  
   `https://github.com/ВАШ_НИК/links/actions`
2. Найдите запуск **Deploy static site to GitHub Pages**
3. Дождитесь зелёной галочки (обычно 30–60 секунд; при первом запуске до 2–3 минут)

---

## Шаг 9. Получите адрес сайта

Вернитесь в **Settings → Pages** (`https://github.com/ВАШ_НИК/links/settings/pages`) — сверху будет баннер:

> Your site is live at **https://ВАШ_НИК.github.io/links/**

Это и есть ваш сайт-переходник. Ссылку можно ставить в профили соцсетей.

---

## 🔄 Как потом менять ссылки или дизайн

Редактировать файлы можно прямо на GitHub или локально, а затем:

```powershell
cd "C:\Users\Администратор\Documents\сайт"
git add .
git commit -m "Обновил ссылки"
git push
```

Сайт пересоберётся автоматически за ~1 минуту.

## 🧩 Частые проблемы

**`git: команда не найдена`** → Git не в PATH. Переустановите с https://git-scm.com/download/win и перезапустите PowerShell.

**В Actions ошибка красного цвета** → Откройте лог, проверьте, что в Settings → Pages источник = *GitHub Actions*.

**Страница 404 после публикации** → Подождите 1–2 минуты и обновите. Проверьте, что workflow завершён зелёным.

**`remote origin already exists`** → Выполните:
```powershell
git remote set-url origin https://github.com/ВАШ_НИК/links.git
```

**`rejected — failed to push`** → В репозитории уже есть файлы. Создайте репозиторий пустым или выполните:
```powershell
git pull --rebase origin main
git push -u origin main
```

**Pages не в Source** → Значит репозиторий private. Смените на Public в Settings → General → внизу Danger Zone.
